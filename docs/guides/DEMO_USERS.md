# 로컬 더미 사용자

`.env`에서 `DEMO_USERS_ENABLED=true`로 설정한 경우에만, `DEBUG=True` 환경의 `migrate`가 아래 계정을 준비합니다. 운영 환경에서는 사용하지 마세요.

| 사용자명 | 권한 | 비밀번호 |
| --- | --- | --- |
| `sampleadmin` | 슈퍼유저 | `DemoOnly123!` |
| `sampleuser01` ~ `sampleuser10` | 일반 사용자 | `DemoOnly123!` |

새 migration은 기존 0003의 프로필 10개를 재사용하며, 이후 `migrate`도 누락 계정을 보완합니다. 기존 일반 사용자와 변경된 비밀번호는 보존하고, 0003이 만든 프로필과 일치하면서 비밀번호가 아직 사용 불가인 샘플만 공개 비밀번호로 전환합니다. `sampleadmin` 이름을 다른 사용자가 이미 쓰고 있으면 관리자 권한을 부여하지 않습니다.
