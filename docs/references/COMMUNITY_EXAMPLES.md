# 팀 게시판 예시 글

10개 구단에 5개씩, 총 50개의 창작 예시 글을 제공합니다.

참고한 게시판:
- 펨코 야구 게시판 및 KBO 분류: https://www.fmkorea.com/baseball
- 엠팍 한국야구타운 및 팀 말머리 글: https://mlbpark.donga.com/mp/b.php?b=kbotown

타순·불펜·수비 토론, 좌석과 원정 질문, 응원·유니폼 잡담 등 주제와 대화체를 참고했습니다. 제목과 본문은 새로 작성했으며 실제 게시글, 닉네임, 경기 결과를 복사하지 않았습니다.

데이터는 `frontend/lib/team-community-examples.ts`에 있고 기존 `getTeamBoardPosts`를 통해 표시됩니다. 기존 게시글 ID와 6자리 번호를 유지합니다. `isSample: true`, 예시 작성자, 날짜 미지정, 조회·추천 0도 유지하며 실제 사용자 활동으로 취급하지 않습니다. 추후 백엔드 게시글 API 연결 시 예시 데이터 대신 서버 응답을 사용합니다.

## 말머리 기준

공통 정의: `frontend/lib/community-post-category.ts`. 팀은 별도 필드로 유지하고 글마다 주된 주제 하나를 지정합니다.

- 잡담: 팬 일상과 가벼운 이야기
- 질문: 다른 말머리로 구체화하기 어려운 규칙·일반 질문
- 응원: 응원가, 응원 메시지
- 경기토론: 개별 경기의 장면·판정·경기 흐름
- 전력토론: 타순, 투수 운용, 수비, 선수 기용
- 소식·정보: 출처가 있는 구단·리그 소식과 유용한 정보
- 이적·신인: FA, 트레이드, 드래프트와 신인 이야기
- 직관후기: 다녀온 경기·구장 경험
- 좌석·예매: 좌석 시야, 표 예매 질문과 정보
- 직관준비: 이동, 식사, 준비물, 방문 일정
- 굿즈: 유니폼, 마킹, 모자, 구단 상품
- 사진·영상: 직접 촬영하거나 이용 가능한 이미지·영상 중심 글

펨코의 정보·자유·경기영상/사진 분류와 엠팍의 직관·트레이드·드래프트 등 말머리를 참고하여 우리 서비스에 맞게 구성했습니다. 예시 글은 실제 본문에 맞는 말머리만 적용하며 소식이나 영상이 없는 글에 해당 말머리를 임의로 붙이지 않습니다. 공지는 일반 주제 선택과 별개인 관리자 권한으로 추후 구현합니다.

## 2026-09-13 예시 글 확장
- 팀별 기존 5개 ID를 유지하고 25개씩 추가해 10팀 총 300개, 자유게시판 50개를 별도 데이터로 작성했습니다. 실제 이용자 글/닉네임/반응수는 복제하지 않았습니다.
- 자유게시판은 잡담·질문만 사용하고 팀 열·제목의 팀명·작성자 프로필의 팀을 숨깁니다. 상세 URL은 /community?post=free-sample-N 이며 목록/이전/다음도 자유게시판으로 연결합니다.
- 팀 ID/번호는 기존 체계를 유지하고 자유게시판 번호는 020001~020050입니다. 페이지당 20개를 유지합니다.
- 참고: https://mlbpark.donga.com/mp/b.php?b=kbotown 및 직관 검색 목록. 타순·수비·직관 준비·굿즈 등 일반 주제를 참고해 새로 작성했습니다. 펨코 https://www.fmkorea.com/baseball 는 이번 조회 시 429 제한으로 본문을 확인하지 못했습니다.
- 데이터는 fictional fixture이며 백엔드 배포용 회원 게시글로 자동 등록하지 않습니다.
