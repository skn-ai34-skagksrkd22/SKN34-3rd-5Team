# 구장별 주차 위치 안내도

사용자가 최종 제공한 KBO 9개 구장의 주차 위치 이미지를 구장별로 연결했다. 이전 주차 이미지는 제거하고 최종 전달본만 서비스 팝업에서 표시한다.

## 구현 위치

- 구장별 메타데이터: `frontend/lib/stadium-parking-maps.ts`
- 팝업 UI: `frontend/components/stadium-parking-map-dialog.tsx`
- 최종 이미지: `frontend/public/images/stadiums/parking-maps/`

## 사용할 때 지킬 기준

- 안내 문구는 위치 관계를 간단히 설명하는 자료이며 길찾기용 좌표 데이터가 아니다. 지도 핀이나 길찾기 기능에는 별도로 확인한 좌표를 사용한다.
- 고척 안내는 한 개 주차장이 아니라 구장 내부 주차 불가와 여러 인근 대체 주차장을 설명한다.
- 수원 안내는 주차 면보다 이용 가능한 출입구와 동문 제한을 설명한다.
- 경기일·행사일의 통제, 운영시간과 이용 가능 여부는 달라질 수 있으므로 최신 구단·시설 안내 확인 문구를 함께 둔다.
- 화면에는 지도 제공사 UI나 지도 타일을 포함하지 않는다. 정보 참고 출처는 `자리어때(myseatcheck.com)`로 표시하고 메타데이터의 `sourcePageUrl`을 연결한다.

## 출처

주차 위치 정보는 자리어때의 각 KBO 구장 주차 안내 페이지에서 2026-09-10에 확인했다. 개별 원문 주소는 `frontend/lib/stadium-parking-maps.ts`의 `sourcePageUrl`에 보관한다. 잠실은 LG 트윈스와 두산 베어스가 함께 사용하므로 한 장으로 관리한다.
