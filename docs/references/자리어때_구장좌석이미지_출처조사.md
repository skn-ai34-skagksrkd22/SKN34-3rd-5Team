# 자리어때 구장·좌석 이미지 출처 조사

- 확인일: 2026-09-10
- 확인 사이트: [자리어때](https://myseatcheck.com/)
- 조사 목적: 자리어때의 구장 배치도와 좌석 시야 사진이 어디에서 제공되는지 확인

## 결론

자리어때 구장 상세 화면의 배치도와 좌석 시야 사진은 KBO 또는 예매 사이트 API에서 실시간으로 받아오는 자료가 아니다. 자리어때가 사용하는 워드프레스 서버의 미디어 폴더에 업로드된 정적 이미지다.

대표적인 이미지 경로는 다음과 같다.

```text
https://myseatcheck.com/wp-content/uploads/{연도}/{월}/{파일명}
```

따라서 페이지를 열 때 다른 서비스에서 이미지를 다시 크롤링하는 구조가 아니라, 자리어때 서버에 저장된 파일을 직접 표시하는 구조다.

## 좌석 화면 동작 구조

1. 구장 페이지에 전체 좌석 배치도를 표시한다.
2. 배치도 위에 SVG 다각형으로 좌석 구역별 클릭 영역을 올린다.
3. 사용자가 구역을 누르면 자리어때 내부의 구역별 상세 페이지로 이동한다.
4. 상세 페이지가 해당 구역의 좌석 시야 사진을 표시한다.

좌석 배치도와 클릭 영역에는 워드프레스의 **Image Map Pro** 플러그인이 사용되고 있다. 잠실 페이지에서 확인한 이미지맵 ID는 `653`이며, 각 클릭 영역은 `page_id` 형식의 자리어때 내부 페이지와 연결된다.

## 기술적으로 확인된 구성

| 항목 | 확인 내용 |
| --- | --- |
| 사이트 기반 | WordPress |
| 화면 구성 | Elementor 사용 흔적 확인 |
| 좌석 클릭 기능 | Image Map Pro |
| 배치도 클릭 영역 | SVG 다각형(`polygon`) |
| 이미지 저장 위치 | 자리어때의 `/wp-content/uploads/` |
| 구역 이동 방식 | 자리어때 내부 상세 페이지 링크 |
| 외부 실시간 이미지 API | 확인되지 않음 |

## 우리 프로젝트에서 적용할 경우

동일한 사용자 경험은 다음 구조로 구현할 수 있다.

1. 구장별 전체 좌석 배치도를 프로젝트 정적 이미지 또는 백엔드 저장소에 보관한다.
2. 배치도 위에 SVG 좌석 구역을 정의한다.
3. 좌석 구역을 누르면 `/stadiums/{stadiumId}/sections/{sectionId}`로 이동한다.
4. 백엔드가 구역 이름, 층, 블록, 시야 사진 목록을 응답한다.
5. 프론트엔드가 사진 갤러리와 구역 정보를 표시한다.

권장 데이터 예시는 다음과 같다.

```json
{
  "stadiumId": "jamsil",
  "sectionId": "401",
  "sectionName": "외야석 401구역",
  "mapArea": {
    "type": "polygon",
    "points": [[774, 446], [797, 405], [844, 378]]
  },
  "images": [
    "/images/stadiums/jamsil/sections/401/001.png"
  ]
}
```

현재 수집한 9개 구장 주차장 지도는 아래 폴더에 별도로 정리돼 있다.

```text
frontend/public/images/stadiums/parking-maps/
```

각 이미지의 원본 페이지와 주소는 해당 폴더의 `SOURCES.md`에서 확인할 수 있다.

## 이미지 사용 시 확인할 점

자리어때 페이지 하단에는 사진 사용 시 출처 표기를 요청하는 문구와 무단 사용에 대한 경고가 함께 표시된다. 출처 표기만으로 복제와 재배포가 허용된다고 단정할 수 없으므로, 좌석 시야 사진을 프로젝트에 대량 저장하거나 외부에 배포하기 전에는 자리어때 측에 사용 범위를 확인하는 것이 좋다.

자체 서비스용으로는 직접 촬영한 사진, 팀이 사용 허가를 받은 자료, 사용자 제보 사진과 이용 동의를 기반으로 데이터셋을 구성하는 방법이 적합하다.
