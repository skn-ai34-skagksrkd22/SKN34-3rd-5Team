# 메인 경기 카드 날씨

- 기상청 단기예보 getVilageFcst, KMA_SERVICE_KEY 또는 기존 KMA_API_KEY 사용. Encoding/Decoding 키 모두 처리하며 브라우저로 키를 전달하지 않습니다.
- 구장 좌표를 기상청 5km 격자로 변환하고 경기 날짜/시각의 가장 가까운 정시 예보를 선택합니다. 30분은 다음 정시입니다. 발표 후 1시간 여유, 경기 시작 이전 발표 기준.
- 서버 캐시 10분, 클라이언트 갱신 10분. 실패/시간 미정/알 수 없는 구장/예보 없음은 날씨 정보 없음으로 표시합니다. 경기 데이터는 독립적으로 유지합니다.
- VS 밑 날씨/기온 두 줄. 출처는 기상청이며 고척은 외부 날씨입니다. 우천취소 판정에 사용하지 않습니다.
- 실제 네트워크 확인: 잠실 2026-09-13 17시 예보 정상 수신. 초기 키 이중 인코딩 오류 수정.
- 공식 문서: https://www.data.go.kr/data/15084084/openapi.do
